# 💧 Drink Water Reminder

## 📌 Description
A simple Python application that reminds users to drink water at regular intervals using desktop notifications. Built with the plyer library, this tool helps promote healthy habits while working on a computer.

---

## 🚀 Features
- Desktop notifications for reminders
- Runs continuously in the background
- Lightweight and easy to use
- Helps maintain hydration habits

---

## ⚙️ How to Run

### 1. Clone the repository
```bash
git clone https://github.com/Chahat-Pal/drink-water-reminder.git
cd drink-water-reminder
```
### 2. Install dependencies
pip install plyer

### 3. Run the program
python main.py

## 💻 How it Works
- The program sends a notification after a fixed interval
- It keeps running in a loop to remind you repeatedly
- ⏱ Default Interval
- Currently set to 36 seconds (for testing)
- You can increase it (e.g., 1800 seconds = 30 minutes)
